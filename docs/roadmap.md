# Roadmap

## Phase 1: 프로젝트 기반

- Rust API 서버 골격
- Python Strategy 서버 골격
- Web 대시보드 골격
- Docker Compose 실행 환경
- 환경변수 기반 설정

## Phase 2: 모의투자 연동

- 한국투자증권 OAuth 토큰 발급: 완료
- 잔고 조회: 완료
- 현재가 조회: 완료
- 모의투자 매수/매도
- 주문/체결 로그 저장

## Phase 3: 안전한 자동매매

- 자동매매 ON/OFF
- 관심종목 관리
- 손절/익절 규칙
- 종목별 최대 비중
- 하루 손실 제한
- 중복 주문 방지

## Phase 4: AI 판단 보조

- AI 매매 제안
- 판단 근거 저장
- 사용자 승인 후 주문
- 전략별 성과 리포트

## Phase 5: 백테스트

- 과거 시세 수집
- 전략 성과 비교
- 수수료와 세금 반영
- 최대 낙폭, 승률, 손익비 계산

## Phase 6: VPS 이전

- DB 백업/복원
- HTTPS 적용
- VPN 또는 접근 제한
- 운영 모니터링
- 장애 알림
