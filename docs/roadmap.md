## News AI Trading Roadmap

### 1. 실제 AI 뉴스 분석 검증

- `OPENAI_API_KEY` 설정
- 사용할 모델과 일일 분석 건수 결정
- 실제 뉴스로 요약, 감성, 중요도, 관련 종목 정확도 확인
- API 비용과 처리 시간 기록

### 2. 뉴스와 국내 종목 연결

- AI가 반환한 회사명을 `data/stocks.json`의 정확한 종목코드로 매핑
- 동명이인, 계열사, 우선주 구분
- 확실하지 않은 결과는 매매 후보에서 제외
- 종목별 관련 뉴스 묶음 제공

### 3. 중복 사건 통합

- [x] 같은 사건을 다룬 여러 기사를 하나의 뉴스 이벤트로 통합
- [x] 단순 기사 개수가 매매 신뢰도를 부풀리지 않도록 방지
- [x] 출처 수와 근거 신뢰도를 별도로 계산

구현 기준: 정규화한 제목의 핵심어 유사도와 확인된 종목코드가 일치하고 발행 시각이 72시간 이내인 기사를 묶는다. 종목별 감성은 이벤트당 한 번만 반영하며 근거 신뢰도는 출처 다양성, AI 분석 완료율, 이벤트 최고 중요도로 계산한다.

### 4. 종목별 일일 AI 전망 생성

- [x] 여러 뉴스 이벤트 분석 결과를 종목별로 종합
- [x] 매수 후보, 매도 후보, 관망 생성
- [x] 신뢰도, 예상 영향 기간, 주요 근거 기록
- [x] 전망을 한국 시간 날짜별로 저장하고 주문과 분리

### 5. 가격·거래량 데이터 결합

- [x] 현재가, 전일 대비, 거래량, 장중 변동성을 AI 전망과 결합
- [x] 매수 후보가 5% 이상 상승했거나 변동성이 10% 이상이면 차단
- [x] 뉴스 영향 기간에 따라 만료 시각을 저장하고 만료 상태로 전환

현재 단계의 차단은 전망 상태만 기록하며 주문을 실행하지 않는다. 이후 뉴스 기반 모의매매 결정 엔진이 `eligible` 상태만 후보로 사용할 예정이다.

### 6. AI 후보 종목 자동 발굴

- [x] 사용자가 등록한 관심종목과 독립적으로 뉴스 종목 후보 계산
- [x] 오늘의 뉴스 전망에서 발견한 종목을 자동 후보군에 추가
- [x] 거래정지, 비정상 상태, 시장경고, 유동성 부족 종목 제외
- [x] 실제 관심종목 포함 여부와 신규 AI 후보를 화면에서 구분

후보군은 관심종목 파일을 수정하지 않는 파생 데이터다. 누적 거래량 1만 주와 추정 거래대금 1억 원을 최소 유동성 기준으로 사용하고, 제외된 종목도 사유와 함께 보존한다.

### 7. 뉴스 기반 모의매매 결정 엔진

- [x] AI 전망과 가격 조건을 이용해 매수, 매도, 관망 결정
- [x] AI 신뢰도 기반 후보에 예산 범위 내 주문 수량 제안
- [x] 기존 예산, 주문 한도, 종목 비중, 보유 수량 위험관리를 마지막에 적용
- [x] 모든 결정에 사용된 뉴스 이벤트와 근거 저장

결정 엔진은 `ready_for_review`, `blocked`, `hold` 상태만 만들며 주문 API를 호출하지 않는다. 제안 수량은 전체 자동매매 예산, 주문당 한도, 종목별 일일 한도, 최대 종목 비중과 실제 보유 수량을 넘지 않는다. 실제 주문 연결은 별도 사용자 승인 단계 이후에만 추가한다.

### 8. 성과 추적

- [x] AI 판단 시점 가격과 이후 가격 비교
- [x] 1일, 3일, 5일 후 수익률 측정
- [x] 감성 구간별 적중률, 종목별 성과, 평균 방향 수익률, 누적 최대 낙폭 집계
- [x] 성과가 나쁜 종목 또는 감성 구간 신호는 자동매매 후보에서 제외

최초 결정 가격은 변경하지 않고 평가 기준가로 고정한다. API 서버가 한 시간마다 만기된 평가를 갱신하며 대시보드에서도 수동 평가할 수 있다. 매수는 가격 상승, 매도는 가격 하락을 방향 적중으로 계산하고 관망은 가격 변화만 기록한다. 자동 제외 추천값은 최소 1일 표본 20건, 적중률 45%, 평균 방향 수익률 0%, 최대 낙폭 10%이며 대시보드에서 언제든 수정하거나 중지할 수 있다. 표본이 기준보다 적으면 차단하지 않고, 제외된 신호도 성과 추적을 계속해 회복 여부를 재평가한다.
